# A 股短线观察法：astock-teacher

这是一套从 2026-09-17 三张聊天截图**归纳**出的观察框架，不是该股民亲自公布的完整交易系统。截图只有一天，未给出完整买卖点、仓位和止损规则；不要把后续上涨反推成他当时已经给出了可执行买点。

## 原始发言对应的判断线索

| 截图中的线索 | 可复用的观察问题 | 不应推出的结论 |
|---|---|---|
| “昨天哈药强，今天百花强”“百花主动上板” | 同一题材中，领涨股是否换手、轮动？新领涨是否有真实成交和板块呼应？ | 任何涨停股都可追。 |
| “永和智控今天竞价 334W，昨天才 16W”“开盘去追我是不理解的” | 竞价量能较自身前几日有多异常？异常是承接还是高开兑现？ | 把 `334W` 当成通用阈值；截图没有定义 W 的单位。 |
| “高争没有跟着爱丽跳，均线上承接”“海星翻红”“大金看 5 日线承接” | 个股相对同题材股票和指数是否抗跌？回踩后能否重新站稳日线 MA5？ | 碰到 MA5 就必然反弹。 |
| “药明大趋势代表”“中材科技主板龙一，中国巨石其次” | 题材是否有大市值锚点、主板龙头和跟随股共同确认？ | 龙头身份固定不变，或所有跟随股同涨。 |
| “偏容量”“更稳妥的持仓”“出监管预期先做完” | 区分原有持仓与新开仓；成交量、换手、监管或异动风险会怎样改变交易难度？ | 持仓逻辑可以直接复制为追入逻辑。 |

## 分析流程

1. **固定时点与交易问题。** 记录分析时间、股票代码、当时是否已有仓位，以及任务是观察、计划新开仓、管理持仓还是事后复盘。只使用该时点已公布的数据；拿不到历史竞价或盘中快照时明确写“无法验证”，不要用收盘数据替代。
2. **先看题材，再看个股。** 确定市场正在交易的题材、同题材领涨与跟随、前一日强势股和当天新强势股。比较涨跌、成交、涨停或炸板状态、板块资金与同伴联动，判断资金是扩散、轮动还是退潮。所谓“主力”“老庄意图”只能作为假设，不能从单日量价证明。
3. **比较竞价与流动性。** 将竞价成交额或成交量与该股此前可比交易日对照，同时看高开幅度、流通规模和开盘后成交。量能突增只说明关注度或分歧增加；需要盘中承接来区分主动买入与兑现。截图中的 334W/16W 不设为阈值。
4. **等盘中确认。** 观察个股相对题材龙头、板块和指数的强弱；回踩 MA5 后是否收回、是否放量承接、是否出现高开低走或炸板。日线 MA5 是动态参考位，需以当时已完成的历史日线计算，并说明盘中实时价格与前收盘计算的 MA5 口径；不要把收盘后形成的均线当成早盘已知值。
5. **分别给出持有与新买结论。** 对已有仓位说明继续持有的依据和失效条件；对新开仓另列可观察的触发条件、可成交性及不追价的理由。若监管、重点监控、异动、停牌或公告会改变预期，把它们列为独立风险事实，不靠猜测监管落地时间交易。

输出时用“事实 → 推断 → 待确认 → 失效条件”组织每只股票，标注价格和数据的时间点。结论用“观察 / 条件满足后关注 / 持有条件尚在 / 条件失效”这类条件化表述；不要把一次截图归纳成无条件买卖指令，也不要自造评分权重或收益保证。

## 在本仓库取数

需要真实行情时，按仓库根目录 [`SKILL.md`](../../../SKILL.md) 中的对应章节使用已有函数：`tencent_quote()` 看实时价，`tencent_kline()` 看日线、MA5 所需历史价及分钟走势，`tencent_ticks()` 看**最近一个交易日**逐笔和 09:25 集合竞价成交；`em_zt_pool()`、`em_zb_pool()`、`em_yzt_pool()` 和 `limit_up_sentiment()` 看涨停接力；`board_fund_flow()` 看板块资金；`em_stock_monitor()` 与 `em_price_anomaly()` 核实监控和异动。先确认接口的时间覆盖、市场覆盖和返回值，再下结论。历史某日的盘中竞价与逐笔若无当时留存的数据，本项目现有接口不能完整重建；当前板块归属、当前资金排名也不能冒充历史时点状态。

## 回测口径

- 先把每条原话标成“实际买入 / 明确看多 / 条件看多 / 仅提及 / 明确回避”，同股多次发言只算一个独立信号；分别报告严格口径与宽口径，不把所有被点名股票算作推荐。
- 信号形成后才可入场。若只有日期而无可验证的盘中价格，用**下一交易日开盘价**作统一代理；已涨停、高开无法保证成交的股票标注成交假设。卖出日期、持有期、止损和仓位须在算收益前确定，不按事后最高点调整。
- 计算单股总收益、胜率与等金额组合收益；除权除息跨期计入分红，列明税费和滑点假设。与同期指数及对应板块比较，并说明样本数、独立交易日数和结论对买卖口径的敏感性。
- 截图里的“我买了点新华制药”没有成交价与仓位，因此可评估信号后的代理收益，不能声称算出了本人实盘收益。
